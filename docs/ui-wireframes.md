# Макеты интерфейса (этап 0)

Панель живёт внутри Home Assistant (`panel_custom`), без внешнего веб-сервера.
Данные — только через WebSocket `ha_smart_analyst/overview` и сервисные действия;
модель не получает свободного доступа к HA API.

## 1. Общий каркас

```
┌──────────────────────────── HA Smart Analyst ─────────────────────────────┐
│ Обзор │ Системы и датчики │ Связи │ Правила │ Инциденты │ Отчёты │ ИИ │ …  │
├───────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐      │
│  │ Активные     │ │ Критические  │ │ Правила      │ │ Очередь      │      │
│  │ инциденты 2  │ │ 1            │ │ 12 / 14      │ │ 0            │      │
│  └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘      │
│                                                                           │
│  Последнее обновление: 30.10.2026 20:00 (Europe/Samara)                   │
└───────────────────────────────────────────────────────────────────────────┘
```

Вкладки (`UI-02`): «Обзор», «Системы и датчики», «Связи», «Правила», «Инциденты»,
«Отчёты», «ИИ», «Telegram», «История», «Диагностика». Переключение — кнопки с
`role="tablist"`; стрелки/Enter/Space работают с клавиатуры; активная вкладка имеет
`aria-selected="true"`.

## 2. Системы и датчики

```
┌ Отопление ──────────────────────────────── [Добавить измерение] ─────────┐
│ Измерение        Роль      Значение      Качество   Сущность             │
│ Подача котла     supply    57,8 °C       ок         sensor.boiler_supply │
│ Цель котла       setpoint  60,0 °C       ок         number.boiler_target │
│ Протечка         leak      —             недоступно binary_sensor.leak   │
│                                                                          │
│ ⚠ Сущность binary_sensor.leak недоступна 3 мин — это качество данных,    │
│   не подтверждённая авария.                                              │
└──────────────────────────────────────────────────────────────────────────┘
```

Правила отображения:

* качество `stale/unavailable/unknown/invalid` показывается текстом, а не цветом
  (цвет — вспомогательный);
* «нет данных» никогда не превращается в «0» или «норма»;
* переименованная сущность показывается как «связь требует внимания» (`ENT-04`).

## 3. Конструктор правила

```
┌ Правило: Перенапряжение L1 ────────────────────────────── [Тест] [Сохранить] ┐
│ Критичность: ( ) info  (•) warning  ( ) critical                             │
│ Политика при отсутствии данных: [unknown ▾]                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ ВСЕ из:                                                                      │
│  ├─ Напряжение L1  [ >  ] [245] [V]                     ← подсветка ошибок    │
│  ├─ Длительность   [30] с                                                    │
│  └─ ИЛИ:                                                                     │
│      ├─ Протечка [состояние =] [on]                                          │
│      └─ НЕ:  Насос [выключен]                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│ Восстановление: ниже [242] [V] в течение [60] с                              │
│ Повтор: [3600] с   Cooldown: [0] с   Debounce: [120] с                       │
└──────────────────────────────────────────────────────────────────────────────┘
```

* Блоки `ВСЕ / ИЛИ / НЕ` вкладываются; глубина ограничена 8, узлов — 200.
* Несовместимые единицы блокируются до сохранения; предлагается перевод.
* Несуществующая сущность подсвечивается, сохранение отклоняется.
* Кнопка «Тест» показывает результат и причины:

```
Результат: UNKNOWN
  • Напряжение L1: качество данных stale (последнее сообщение 41 мин назад)
  • Условие «> 245 V» не вычислено: значение недоступно
```

Три состояния результата различаются текстом и иконкой: ✅ true, ❌ false, ❔ unknown.
«UNKNOWN» не окрашивается как авария.

## 4. Инциденты

```
┌ Инциденты ────────────────────────────────────────────────────────────────┐
│ Критичность  Правило            Состояние    Открыт      Пик     Принято  │
│ CRITICAL     Протечка           OPEN         20:01        —       нет      │
│ WARNING      Перенапряжение L1  ACKNOWLEDGED 19:40        12,8 V  да       │
│                                                                           │
│ [Принять] [Подробности] [Отключить повторы на 1 час]                      │
└───────────────────────────────────────────────────────────────────────────┘
```

* «Принять» пишет ACK и **не** закрывает инцидент (`INC-01`).
* «Отключить повторы» подавляет только оповещения; инцидент остаётся в журнале.
* Ручное закрытие — отдельное действие с обязательной пометкой и подтверждением.

## 5. Отчёты

```
┌ Отчёт 20:00 (Europe/Samara) ──────────────────────────────────────────────┐
│ Факты (локально)                          │ Вывод ИИ (не факты)            │
│ Подача: 57,8 °C                           │ Краткое заключение…            │
│ Цель: 60,0 °C                             │ Гипотезы: …                    │
│ Отклонение: −2,2 °C                       │ Ограничения: нет истории       │
│ Покрытие истории: 0%; тренд: нет данных    │ Числа без подтверждения: 7,5   │
└───────────────────────────────────────────────────────────────────────────┘
```

* Блоки визуально разделены; факты нельзя отключить.
* При недоступном ИИ показывается шаблонный отчёт, а не пустота.
* «Разброс фазных напряжений» — не «коэффициент несимметрии» (`REP-06`).

## 6. Мобильная адаптация

* Брейкпоинты: 375 / 768 / 1024 / 1440.
* Вкладки переносятся в две строки, таблицы прокручиваются горизонтально,
  кнопки остаются не меньше 44×44 px.
* Никаких фиксированных высот карточек «для выравнивания».

## 7. Доступность (чек-лист)

* Видимый фокус: `outline: 2px solid var(--primary-color); outline-offset: 2px`.
  Акцент блоков — `box-shadow`, не `outline`.
* Контраст текста ≥ 4,5:1; статусы дублируются текстом.
* Переходы 150–300 мс, без анимации при `prefers-reduced-motion`.
* Опасные операции (удаление правила, ручное закрытие инцидента) — подтверждение
  с перечислением зависимых объектов.
* Ошибки формы — рядом с полем и в сводке, `role="alert"`.

## 8. Пустые и аварийные состояния

| Состояние | Текст | Действие |
|---|---|---|
| Нет систем | «Добавьте первую группу» | кнопка добавления |
| Нет истории | «Recorder недоступен — тренды не рассчитываются» | ссылка на настройки Recorder |
| ИИ недоступен | «DeepSeek не ответил: HTTP 401» | кнопка «Повторить», без бесконечных попыток |
| Очередь переполнена | «Старые информационные сообщения удалены» | показать счётчик |
| Связь разорвана | «Сущность переименована или удалена» | предложить восстановление |
